## 服务状态与公开边界

- 当前首页、搜索入口和抽样书籍页均可访问，详情见 [服务状态](STATUS.md)。
- 本仓库公开哪些事实、如何核验以及哪些内容不公开，见 [透明度说明](TRANSPARENCY.md)。
- 文件、格式和下载通道会变化，不承诺每本书的所有资源永久可用。
- 当前流程没有自动版权归属判断；权利反馈和下架处理方式见 [内容处理说明](CONTENT-POLICY.md)。
- 本站增长统计采用有限聚合口径，详见 [隐私与数据说明](PRIVACY.md)。
- 面向用户的重要仓库变更记录在 [CHANGELOG.md](CHANGELOG.md)。
